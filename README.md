# Maryrose Camille — Executive VA Portfolio

Personal portfolio for **Maryrose Camille Acyatan**, positioned around AI-powered executive support, Google Workspace, workflow organization, and executive operations.

## Positioning

**AI-Powered Executive VA | Google Workspace & Workflow Automation | Executive Operations**

The portfolio connects experience in application support, administrative support, customer operations, sales, and technical support with practical Executive VA workflows.

## Featured portfolio demonstrations

- **Executive Command Center** — priorities, meetings, deadlines, owners, and follow-up tracking.
- **AI Meeting-to-Action Workflow** — meeting notes to executive summary, decisions, action items, and follow-up draft.
- **Executive Inbox & Follow-Up System** — inbox triage, decision queues, routine responses, and open-loop tracking.

These projects are explicitly presented as **portfolio demonstrations** using fictional scenarios or data. They are not represented as commissioned client work.

## Core toolkit

Google Workspace, Gemini for Workspace, ChatGPT, Salesforce, and Google Apps Script foundations.

## Run locally

```bash
npm install
npm run dev
npm run build
npm run lint
npm run typecheck
```

## Content structure

- Identity and contact: `src/data/profile.ts`
- About: `src/components/AboutGrid.tsx`
- Services: `src/components/ServicesGrid.tsx`
- Projects/case studies: `src/components/ProjectsGrid.tsx` and `src/components/ProjectPanels.tsx`
- Experience and credentials: `src/components/TestimonialsGrid.tsx`
- FAQs: `src/data/faqs.ts`
- Contact: `src/components/ContactGrid.tsx`
- SEO metadata: `index.html`

## Stack

Vite 6, React 19, TypeScript, React Router, Three.js, GSAP, Lenis, Phosphor icons, and CSS custom properties.
